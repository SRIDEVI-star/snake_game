# 🐍 Snake Game

A simple and fun **Snake Game** built in two different versions — **HTML/CSS/JavaScript** and **Python Tkinter** 🎮

Both versions are fully functional and can be run directly from **VS Code**.

---

## 🎮 Features

✨ Classic Snake gameplay  
🍎 Eat the food and grow longer  
🏆 Score and best-score tracking  
⚡ Snake gets faster as your score increases  
💀 Game-over detection  
🔄 Restart the game anytime  
⏸️ Pause and resume  
⌨️ Arrow keys and WASD controls  

---

# 🌐 Version 1 — HTML

The HTML version runs directly in your web browser.

### ▶️ How to Run

1. Open the **HTML file** in VS Code.
2. Make sure the **Live Server** extension is installed in VS Code.
3. Open the HTML file.
4. Click **"Go Live"** at the bottom-right corner of VS Code.
5. 🌐 The Snake game will open automatically in your browser.

### 🎮 Controls

- ⬆️ **Arrow Up / W** → Move Up
- ⬇️ **Arrow Down / S** → Move Down
- ⬅️ **Arrow Left / A** → Move Left
- ➡️ **Arrow Right / D** → Move Right
- ⏸️ **Space** → Pause / Resume
- 🔄 **R** → Restart

---

# 🐍 Version 2 — Python

The Python version uses **Tkinter**, Python's built-in GUI library.

No additional packages or `pip install` are required.

### ▶️ How to Run

1. Open the **Python file** in VS Code.
2. Look at the **top-right corner** of VS Code.
3. Click the **▶️ Run Python File** button.
4. 🐍 The Snake game will open in a separate window.

### 🎮 Controls

- ⬆️ **Arrow Up / W** → Move Up
- ⬇️ **Arrow Down / S** → Move Down
- ⬅️ **Arrow Left / A** → Move Left
- ➡️ **Arrow Right / D** → Move Right
- ⏸️ **Space** → Pause / Resume
- 🔄 **R** → Restart
